# Alternatives

Backtesting engines encode many assumptions about execution, accounting, and market mechanics. Review those assumptions before trusting results.

Related Python projects include:

- [AutoTrader](https://github.com/kieran-mackle/AutoTrader): automated trading framework with backtesting support.
- [bt](http://pmorissette.github.io/bt/): reusable blocks for multi-instrument strategy logic and charts.
- [vectorbt](https://polakowo.io/vectorbt/): pandas-based strategy analysis at scale.
- [Backtrader](https://www.backtrader.com/): feature-rich Python framework for backtesting and live trading.
- [PyAlgoTrade](https://gbeced.github.io/pyalgotrade/): event-driven backtesting and live-trading support.
- [Pinkfish](http://fja05680.github.io/pinkfish/): lightweight intraday-on-daily backtesting.
- [finmarketpy](https://github.com/cuemacro/finmarketpy): financial market data analysis.
- [QSTrader](https://github.com/mhallsmoore/qstrader/): modular schedule-driven backtesting.
- [pysystemtrade](https://github.com/robcarver17/pysystemtrade): systematic trading engine from Robert Carver.
- [QTPyLib](https://github.com/ranaroussi/qtpylib): event-driven algorithmic trading library.
- [Nautilus Trader](https://github.com/nautechsystems/nautilus_trader): production-grade algorithmic trading platform with Python/Rust components.
- [AwesomeQuant](https://github.com/wilsonfreitas/awesome-quant#trading--backtesting): broader list of quant and trading resources.

Older or less maintained projects that may still be useful for comparison:

- [Zipline](https://www.zipline.io/)
- [AlephNull](https://github.com/CarterBain/AlephNull)
- [pybacktest](https://github.com/ematvey/pybacktest)

- [visualize-wealth](https://github.com/benjaminmgross/visualize-wealth)
